# For You · Birthday Surprise — WebBunon demo
এটি কাল্পনিক ব্র্যান্ডের সম্পূর্ণ নমুনা ওয়েবসাইট। কোনো বাস্তব ব্যবসার দাবি, অর্ডার, বুকিং বা পেমেন্ট নেই।

GitHub Pages: ZIP extract করে index.html, style.css, app.js, assets ও অন্য সব ফাইল repository root-এ দিন। Settings > Pages > main > /(root) > Save। Build/install লাগে না।
লেখা: index.html। ডিজাইন: style.css। কার্যক্রম: app.js। ছবি: assets/sheet.png (থাকলে)।
ফর্ম শুধু সারাংশ দেখায়/কপি করে, কোনো তথ্য পাঠায় না। প্রকাশের আগে নমুনা যোগাযোগের পরিবর্তে নিজের যাচাই করা ব্যবসার তথ্য বসান।
