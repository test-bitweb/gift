# WebBunon Gift Demo — Ready-made photo edition

A finished fictional birthday gift for Maya from Arian. Includes three sample photos: together, her portrait and his portrait. No photo uploads, editor or personalization controls.

Upload index.html, style.css, app.js and the assets folder together to your GitHub repository root. Enable GitHub Pages. No build required.

Interactions: open the surprise letter, reveal memory cards, enlarge photos, responsive mobile menu and countdown to 15 December.

All names, stories and photos are illustrative demo content. Change the static HTML and assets if you later want to customize this for a customer.
