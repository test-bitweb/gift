# Gift Website — Photos edition

Upload all files to your GitHub Pages repository root, or open index.html locally.

Add Together, You and Me photos. JPG/PNG/WebP, up to 8 MB each. Click a photo to enlarge it; use Remove to remove it. Photos remain in this page session until you download the personalized website.

Set name, message and date. Click Download personalized website. The downloaded index.html embeds all three photos, your text, styles and scripts. Upload THAT index.html to GitHub to let other visitors see your chosen photos. It also works as a standalone file. Font loading is optional; system fallbacks are included.

Uploading pictures in the editor does not automatically change the live GitHub website. Publish the downloaded index.html. Use only photos you want visitors to see.

Demo brand and sample text are fictional. No server, database or payment system.
