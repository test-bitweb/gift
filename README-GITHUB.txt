WEBBUNON LOVE BOOK — GITHUB PAGES

1. Unzip this file.
2. Create a GitHub repository.
3. Upload index.html, style.css, app.js, assets/ and vendor/ directly into the repository root. Do not upload the ZIP itself.
4. Open repository Settings > Pages. Select Deploy from a branch, then main and /(root), and Save.
5. GitHub will display your website address after deployment.

No build command or API key required. Keep folder names unchanged.

CUSTOMIZE
Edit pages and notes in app.js. Replace pictures in assets/.
WebBunon branding is present on the front and back covers; both link to the business Facebook page.
Music starts only when a visitor presses Play/Music. Dreams are stored for the current session only. Sample names and pictures are illustrative.

Dependency: StPageFlip 2.0.7, MIT; license included in vendor/.
